# Contribution Workflow

1. Pick a lesson, open/assign its issue (use the *Lesson task* template).
2. Branch: `lesson/m03-l04-instruction-cycle`.
3. Update `script.md` status as you progress.
4. Open a PR; reviewer checks technical accuracy and the QA checklist.
5. Squash-merge. Attach final MP4s to a GitHub Release, not to the repo.

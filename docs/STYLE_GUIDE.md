# Style Guide

## Visual
- Background: near-black (#0B0F17), panels #131A26
- Accent colors: cyan #22D3EE (data), amber #F59E0B (control), green #34D399 (OK/hit), red #F87171 (error/miss)
- Font: Inter or Source Sans for labels, JetBrains Mono for code/binary
- Minimum label size: 36 px at 1080p
- Animate step by step; never show a finished diagram without building it up
- Consistent color per signal type across all lessons (data = cyan, address = violet, control = amber)

## Narration
- Simple English, short sentences, define every term the first time
- Explain *why* before *how*
- Pace: ~140 words per minute
- End every lesson with 3 key takeaways and a teaser for the next lesson

## Lesson structure
Hook -> Concept -> Step-by-step demo -> Worked example -> Real-world use -> Recap
